# Burger-joint template (DP-14): its pictures

Six free stock photos from Unsplash, one per picture the boards use. Download each, rename the file to the
**key** shown (the key comes from the file's name when it's uploaded, and the boards ask for it by that key), and
upload them on the counter board's **Pictures** tab in the WayTuGo Templates account. The console shrinks each one
before it's uploaded.

On each page, check that it says **Free to use under the Unsplash License** before downloading. Unsplash+ pictures
need a subscription, so skip one marked Unsplash+ and pick another free one from the same search. The Unsplash License
allows commercial use without credit, but don't use a photo that shows a brand's logo or a recognisable person's face.

The Meet Market is a keto burger bar, so pick burgers **without a bun** (in a lettuce wrap, or on a plate) where you
can, and a shake in a plain glass.

| Key (file name) | Used for | Search |
|---|---|---|
| `double-smash` | Featured: The Double Smash (and the first picture people see) | https://unsplash.com/s/photos/smash-burger |
| `pimento-bacon` | Featured: The Southern Belle (pimento cheese, bacon, jalapeños) | https://unsplash.com/s/photos/bacon-cheeseburger |
| `burger-bowl` | Featured: Burger Bowl (a burger over greens) | https://unsplash.com/s/photos/burger-salad |
| `cheese-chips` | Featured: Fried Cheese Chips with dips | https://unsplash.com/s/photos/cheese-crisps (or "fried cheese") |
| `wings` | Featured: Smoked Wings | https://unsplash.com/s/photos/chicken-wings |
| `keto-shake` | Featured: Keto Chocolate Shake, and the picture beside Shakes & drinks | https://unsplash.com/s/photos/chocolate-milkshake |

Until a picture is uploaded, **Check** lists it as missing, and Publish waits for all six.
