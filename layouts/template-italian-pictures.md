# Italian-American template (T2): its pictures

Nine free stock photos from Unsplash, one per picture the boards use. Download each, rename the file to the **key**
shown (the boards ask for a picture by its key, which comes from the file's name when it's uploaded), and upload them
on the menu board's **Pictures** tab in the WayTuGo Templates account. The console shrinks each one before it's
uploaded.

On each page, check that it says **Free to use under the Unsplash License** before downloading. Unsplash+ pictures need
a subscription, so skip one marked Unsplash+ and pick another free one from the same search. The Unsplash License allows
commercial use without credit, but don't use a photo that shows a brand's logo or a recognisable person's face.
